# Debot

Telegram-бот с четырьмя комедийными режимами, историей диалогов, обработкой текста и фото. Генерация идёт через выбранный облачный API: Alibaba Cloud Model Studio (Qwen) или DeepSeek. Локальная Ollama и объёмная модель на компьютере не нужны.

## Стоимость и защита от списаний

По умолчанию выбран Qwen `qwen3-vl-plus`. Для подходящих аккаунтов Model Studio в регионе Singapore официально указана бесплатная квота 1 млн токенов на модель на 90 дней. Это условие региона и аккаунта, а не гарантированно бесплатный тариф для всех. Вне Singapore этой квоты нет. После её исчерпания обычный pay-as-you-go может начать тарифицироваться.

Для режима без автоматических списаний сначала включи **Free Quota Only** для `qwen3-vl-plus` в Alibaba Cloud Console, дождись подтверждения настройки, затем поставь в `.env` `QWEN_FREE_QUOTA_ONLY_CONFIRMED=true`. Пока флаг не задан, бот откажется запускаться с Qwen. Free Quota Only должен остановить вызовы при исчерпании квоты. Если регион/аккаунт не даёт бесплатную квоту, не подтверждай этот режим; для платного pay-as-you-go нужно отдельно и осознанно выставить `QWEN_ALLOW_PAYG=true`.

DeepSeek тарифицирует по токенам. По умолчанию платные вызовы заблокированы; для включения нужно явно выставить `DEEPSEEK_ALLOW_PAID=true`. Цены и официальные лимиты по обоим сервисам, включая конкретные периоды peak/off-peak и квоты Qwen, записаны в [API_COSTS.md](API_COSTS.md).

В коде установлен общий предел 50 попыток API в сутки по UTC, который хранится в SQLite и переживает перезапуск; дополнительно ограничены длина входа, максимальный ответ и размер фото. Это снижает риск злоупотребления, но **не заменяет Free Quota Only и не является гарантией максимальной суммы счёта**. Telegram Bot API используется только для доставки сообщений; оплата генерации зависит от AI-провайдера.

## Установка

1. Создай Telegram-бота через BotFather. Если старый токен попадал в публичный issue, сначала отзови его и выпусти новый.
2. Для бесплатного режима Qwen создай Workspace в Singapore-регионе Model Studio, получи региональный API-ключ, включи Free Quota Only для `qwen3-vl-plus` и скопируй endpoint этого Workspace. Если бесплатная квота недоступна, остановись здесь либо явно согласись на платный режим. Для DeepSeek создай API-ключ в DeepSeek Platform; DeepSeek в этом боте не запускается без явного `DEEPSEEK_ALLOW_PAID=true`.
3. Python 3.10 или новее и установи зависимости:

   ```bash
   python -m venv .venv
   # Linux/macOS:
   source .venv/bin/activate
   # Windows PowerShell:
   # .venv\\Scripts\\Activate.ps1
   pip install -r requirements.txt
   ```

4. Скопируй `.env.example` в `.env`, заполни `BOT_TOKEN`, ключ и endpoint выбранного провайдера, затем включи только соответствующий режим согласия:

   ```bash
   # Linux/macOS:
   cp .env.example .env
   # Windows PowerShell:
   # Copy-Item .env.example .env
   ```

   Для Qwen с бесплатной квотой выставь `QWEN_FREE_QUOTA_ONLY_CONFIRMED=true` **только после того, как включил Free Quota Only в консоли**. Для платного Qwen вместо него задай `QWEN_ALLOW_PAYG=true`. Для DeepSeek задай `DEEPSEEK_ALLOW_PAID=true`.

5. Запусти бота:

   ```bash
   python bot.py
   ```

   В Telegram отправь `/start`. Ключи не публикуй и не добавляй в Git.

## Команды

- `/start` — начать заново и выбрать режим.
- `/help` — показать подсказку.
- `/reset` — очистить историю текущего диалога.
- `/status` — показать провайдера и сколько API-запросов из суточного лимита уже использовано. Команда не вызывает модель и не расходует токены.

## Настройки `.env`

- `AI_PROVIDER` — `qwen` или `deepseek`; по умолчанию `qwen`.
- `QWEN_API_KEY`, `QWEN_BASE_URL`, `QWEN_MODEL` — региональный ключ, endpoint Workspace и модель; по умолчанию `qwen3-vl-plus`.
- `QWEN_FREE_QUOTA_ONLY_CONFIRMED` — явное подтверждение, что Free Quota Only включён в консоли.
- `QWEN_ALLOW_PAYG` — явно разрешает тарификацию Qwen после квоты.
- `DEEPSEEK_API_KEY`, `DEEPSEEK_BASE_URL`, `DEEPSEEK_MODEL` — настройки DeepSeek; модель по умолчанию `deepseek-flash`.
- `DEEPSEEK_ALLOW_PAID` — явно разрешает платные вызовы DeepSeek.
- `MAX_API_CALLS_PER_DAY` — общий предел попыток для всех пользователей, сбрасывается в полночь UTC; по умолчанию 50. Ошибки API тоже учитываются, чтобы неисправная интеграция не создавала бесконечные повторы.
- `MAX_OUTPUT_TOKENS` — максимум ответа модели, по умолчанию 512.
- `MAX_INPUT_CHARS` — максимальная длина сообщения, по умолчанию 4 000 символов.
- `MAX_IMAGE_MB` — лимит фото, по умолчанию 8 МБ.

История режимов хранится в памяти процесса; счётчик API хранится в `debot_usage.sqlite3`. Для нескольких экземпляров бота используй общий надёжный счётчик/один экземпляр, иначе каждый экземпляр создаст отдельный лимит. RPM/TPM провайдера — отдельные ограничения; при HTTP 429 подожди и проверь квоты аккаунта.
