# Debot

Telegram-бот с четырьмя комедийными режимами, диалоговой историей, обработкой текста и изображений. Генерация идёт через локально запущенную [Ollama](https://ollama.com/) и модель `qwen2.5vl:3b`; Google Generative AI и платные AI API не используются.

## Требования

- Python 3.10 или новее.
- Ollama, установленная на компьютере/сервере, где будет работать бот.
- Telegram-токен от BotFather. В issue #1 старый токен опубликован, поэтому сначала отзови его и создай новый.
- Около 3 ГБ диска для модели; скорость генерации зависит от памяти и CPU/GPU компьютера.

Запросы к Telegram Bot API нужны только для получения сообщений и отправки ответов. Они не запускают платную генерацию; сама языковая и визуальная модель работает локально. Возможные расходы ограничиваются электричеством и ресурсами компьютера/хостинга.

## Установка

1. Установи Ollama с [официального сайта](https://ollama.com/download), затем скачай модель:

   ```bash
   ollama pull qwen2.5vl:3b
   ```

   Ollama должна оставаться запущенной. Проверить установленную модель можно командой `ollama list`.

2. В каталоге проекта создай виртуальное окружение и установи зависимости:

   ```bash
   python -m venv .venv
   # Linux/macOS:
   source .venv/bin/activate
   # Windows PowerShell:
   # .venv\\Scripts\\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируй `.env.example` в `.env` и укажи новый токен:

   ```bash
   # Linux/macOS:
   cp .env.example .env
   # Windows PowerShell:
   # Copy-Item .env.example .env
   ```

   Открой `.env` и задай `BOT_TOKEN`. Не публикуй `.env` и не добавляй токены в код или Git.

4. Запусти бота:

   ```bash
   python bot.py
   ```

   В Telegram отправь `/start`. Кнопками выбираются режимы «Дебил», «Злой», «Откровенный дебил» и «Мемный». Можно отправлять текст и фото с подписью или без неё.

## Команды

- `/start` — начать заново и выбрать режим.
- `/help` — показать подсказку.
- `/reset` — очистить историю текущего диалога.
- `/status` — проверить доступность Ollama и наличие модели.

## Проверки

После установки зависимостей запусти тесты командой `python -m unittest discover -s tests -v`.

## Настройки

Переменные задаются в `.env`:

- `BOT_TOKEN` — новый токен Telegram-бота (обязателен).
- `OLLAMA_BASE_URL` — адрес локального Ollama, по умолчанию `http://127.0.0.1:11434`.
- `OLLAMA_MODEL` — установленная Ollama-модель, по умолчанию `qwen2.5vl:3b`.
- `OLLAMA_TIMEOUT_SECONDS` — тайм-аут генерации, по умолчанию 180 секунд.
- `MAX_IMAGE_MB` — максимальный размер скачиваемого фото, по умолчанию 15 МБ.
- `LOG_LEVEL` — уровень логирования, по умолчанию `INFO`.

Если бот запускается не на том же компьютере, что Ollama, задай `OLLAMA_BASE_URL` как адрес Ollama-сервера, доступный из среды бота. Не выставляй Ollama-порт в открытый интернет без аутентификации и сетевых ограничений.

## Конфиденциальность и стоимость

Вызовы генерации отправляются только на настроенный локальный Ollama-сервер. Текст и фотографии не пересылаются в Google/Gemini или другой сторонний AI-сервис. Telegram всё равно обрабатывает сообщения как оператор платформы. Для фото бот скачивает изображение из Telegram и передаёт байты локальной модели.
