# DeepSeek и Qwen API: тарифы и лимиты

Проверено 20 октября 2026 года по официальным страницам провайдеров. Тарифы, доступность бесплатных квот и квоты аккаунтов могут меняться; перед включением API сверяй их с личной консолью.

## Что включено в бота

Бот поддерживает оба провайдера через OpenAI-compatible Chat Completions, включая передачу фото. По умолчанию выбран `qwen3-vl-plus`; переключение на DeepSeek — `AI_PROVIDER=deepseek`. В коде по умолчанию запрещены вызовы без явного согласия: для Qwen нужен флаг подтверждения Free Quota Only или отдельный флаг согласия на pay-as-you-go; для DeepSeek платные вызовы требуют `DEEPSEEK_ALLOW_PAID=true`.

Также действует общий предел 50 попыток в сутки UTC, сохраняемый в SQLite, и ограничение длины запроса/ответа. Это предохранитель от бесконечных повторов и злоупотребления, но не расчёт гарантированной максимальной суммы счёта.

## Qwen `qwen3-vl-plus`

Model Studio указывает для Singapore/International бесплатную квоту 1 000 000 токенов на модель, действующую 90 дней от более поздней даты активации сервиса, выпуска модели или одобрения доступа. Она доступна только подходящим аккаунтам Singapore-региона; в других регионах этой бесплатной квоты нет. Для Singapore стандартная цена при запросе до 32K входных токенов — $0.20 за миллион входных и $1.60 за миллион выходных токенов; при больших объёмах действует ступенчатая цена.

Бесплатная квота учитывает общий расход входных и выходных токенов и ограничена по времени. Если включён обычный pay-as-you-go, после исчерпания квоты возможны списания. В консоли включи **Free Quota Only** для выбранной модели: после расходования квоты вызовы останавливаются. Бот дополнительно требует `QWEN_FREE_QUOTA_ONLY_CONFIRMED=true`, чтобы оператор явно подтвердил это действие. Этот программный флаг сам по себе не меняет тарифные настройки Alibaba Cloud.

Скоростной лимит отличается от бесплатного объёма. В официальной таблице для модели Singapore/International `qwen3-vl-plus` указаны 1 200 запросов в минуту и 1 000 000 токенов в минуту. Фактические квоты Workspace можно запросить у Model Studio через `GET /api/v1/quotas`; бот этот запрос не делает. При превышении rate limit API обычно возвращает HTTP 429.

## DeepSeek `deepseek-flash`

Официальное имя модели — `deepseek-flash`; текущая версия, указанная в документации на дату проверки, — DeepSeek-V4.1-Flash-1017. Модель принимает текст и фото.

Стоимость зависит от кэширования и времени. Для cache-miss входа тариф составляет $0.15 за миллион токенов в off-peak и $0.30 в peak; выход — $0.60/$1.20 за миллион токенов соответственно. Кэшированные входные токены стоят дешевле. Peak — понедельник–пятница 01:00–04:00 и 06:00–10:00 UTC, за исключением официальных китайских праздников; остальное время off-peak. Оплата рассчитывается по фактическим токенам и списывается с пополненного или выданного баланса. Поэтому DeepSeek не следует считать бесплатным без подтверждённого остатка выданного баланса.

DeepSeek указывает concurrency limit 2 500 одновременных запросов на аккаунт для Flash; при превышении лимита вернётся HTTP 429. Это не суточная бесплатная квота и не ограничение расходов. Бот требует `DEEPSEEK_ALLOW_PAID=true` перед запуском с этим провайдером.
